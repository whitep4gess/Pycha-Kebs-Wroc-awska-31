# Pycha KEBS — strona klienta

Osobna, responsywna strona wizytówka restauracji Pycha KEBS przy ul. Wrocławskiej 31.

## Uruchomienie

Otwórz `index.html` w przeglądarce albo uruchom lokalny serwer w tym folderze.

## Zawartość

- pełne menu przepisane z fotografii,
- prawdziwe zdjęcia jedzenia, logo i lokalu,
- numer telefonu oraz godziny otwarcia,
- odnośnik do lokalizacji w Mapach Google,
- responsywny układ na telefon i komputer.

## Do uzupełnienia

- link do zamawiania online,
- adres e-mail i profile społecznościowe,
- ewentualne zmiany cen lub składników po potwierdzeniu z klientem.
